Conversations across languages.

Linked Translator is a Discord bot that translates messages between linked channels while preserving supported replies and media. It supports server-specific language settings, glossary entries and user corrections.

Translation and optional shared learning

Live translation uses a self-hosted translation service. Background review can select eligible public-channel examples to improve translation rules. Server administrators can view participation and use the bot's learning controls to enable, disable or delete their server's shared contributions. Local corrections take priority over shared rules.

Google Drive connection

The operator authorizes their own Google account to exchange filtered training datasets, evaluation reports, training code and model artifacts between the Oracle server and Google Colab. Google Drive is used for private file storage; these files are not published on this website.

Training runs separately from live translation. Google Colab sessions are started by the operator when resources are available. Tested phrase improvements can be applied to the bot's shared glossary.

Privacy and support

Read our privacy policy for information about Google access, selected Discord examples, storage and deletion. Use is subject to the terms of use.

For support or privacy requests, contact the bot operator through Discord in a server where the bot is installed. The operator's GitHub account is shousaito-bot. Do not post private information in public repository issues.
