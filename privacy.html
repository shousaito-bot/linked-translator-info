Privacy policy

Linked Translator · Operator: shousaito-bot · Updated 25 October 2026

What the application does

Linked Translator relays translated messages between linked Discord channels and supports an optional shared learning pipeline. This policy describes the operator's configured bot, its Google Drive connection and this informational website.

Discord data and learning

Operating the bot involves processing message text, supported media and metadata needed for delivery, configuration and relay mappings. These operational records are separate from learning exports.

After an administrator or owner receives the participation notice, the configured collector may sample eligible public-channel text. Corrections submitted with !fix can also contribute if they pass the applicable review controls. Private messages, restricted channels and sensitive content are excluded from the learning collector. Filters and model checks are imperfect; do not submit secrets or sensitive personal information.

Approved dataset exports contain source and translated text, language codes and, when needed, filtered context. Exports omit Discord account, server, channel and message identifiers, author profiles and internal provenance identifiers. Private provenance records remain on the Oracle host.

Google account access

Only the operator authorizes the Google Drive account. Discord users do not need to connect a Google account to use the bot. The configured Drive permission allows broad access to files in that authorized account. The integration uses a dedicated linked-translator folder to read, create, update and delete its managed files; it is not designed to enumerate or analyze unrelated personal Drive content.

Transferred files include filtered datasets, baseline predictions, revocation lists, credential-free training code, evaluation reports, checkpoints, adapters and proposed glossary rules. Dataset text is used in operator-started Google Colab fine-tuning and evaluation to improve this translation system. Drive file names and metadata are processed as needed to manage those transfers.

OAuth tokens are stored in the operator's private rclone configuration on Oracle. The integration does not intentionally upload the Discord token, webhook credentials, raw SQLite database, environment file or provenance key to Drive or this website.

Storage, providers and sharing

Operational data and provenance are stored on the operator's Oracle server. Google Drive stores the managed files, and Google Colab processes selected training material. Discord handles message delivery. Local translation and review services run on the operator's infrastructure. The integration does not sell Google user data or use it for advertising, and it does not intentionally publish training files or model artifacts. Access is limited to the operator, authorized collaborators and the providers needed for this workflow, subject to their terms and policies.

Retention and deletion

Pending automatic learning examples expire after seven days under the current configuration. Weekly database backups are retained for 35 days. Upgrade backups, exported files and checkpoints may remain until the operator removes them.

Server administrators can use /learning disable to stop contributions and withdraw affected shared learning support. /learning delete removes the server's learning contributions while preserving requested local fixes. Revocations take effect on Oracle immediately; managed Drive exports are removed at the next successful sync. External copies and backups may require separate operator action. Trained weights cannot reliably forget an individual example; affected artifacts must be discarded and retrained.

Revoke Google access

The operator can revoke this application's access from their Google account connections. Revocation stops future authenticated transfers, but does not automatically erase files or prior checkpoints. The operator can remove those from Drive and local storage.

This website

These pages have no application analytics, advertising, forms or client-side scripts. GitHub Pages hosts the public site and may log visitor information, including IP addresses, under GitHub's privacy policy.

Contact and changes

Contact the bot operator through Discord in a server where the bot is installed, or use the contact information on the shousaito-bot GitHub profile when available. Do not include sensitive information in public issues. This page will be updated if the workflow or data practices change.
